
# VBA Projects

This repository contains my practice and learning projects in **Visual Basic for Applications (VBA)**.  
The goal is to build automation skills in Excel and other Microsoft Office applications.

## Contents
- Dynamic scripts for automating repetitive tasks
- Data cleaning and formatting scripts
- UserForm examples
- Advanced projects combining VBA with Excel formulas

## Purpose
- Learn and practice VBA programming
- Organize projects in one place
- Track progress over time

## How to Use
1. Clone or download the repository.
2. Open the `.xlsm` or `.xls` files in Microsoft Excel.
3. Enable macros to run the VBA code.
